# Movie Dub Collection

GitHub Pages + GitHub Codespaces-ready web application.

## Features

- Movie information database
- Language dub collection display
- JSON-powered movie catalog
- Responsive layout
- GitHub Pages compatible

## Movie Entry

### Cinderella

- Year: 1950
- Studio: Walt Disney Productions
- Category: Animated Feature
- Collection Type: Language

## Run in Codespaces

1. Open repository in GitHub Codespaces
2. Start Live Server or run a local web server
3. Open `index.html`

## Deploy to GitHub Pages

Repository Settings → Pages → Deploy from main branch
